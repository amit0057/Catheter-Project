# Catheter-Project

### Objectives
- Develop a CNN capable of analysing X-ray images
- Classify different types of catheters
- Identify whether catheter placement is normal or abnormal
- Investigate different deep learning architectures to improve model performance
- Address data quality and class imbalance challenges within the dataset

### My Contributions
As part of the project team, my responsibilities included:
- Collaborated with team members to design and develop the CNN model
- Researched and experimented with architectures including ResNet and DenseNet
- Performed data cleaning and preprocessing to improve dataset quality
- Addressed significant class imbalance within the dataset
- Evaluated model performance and contributed to discussions around model improvements
- Communicated findings clearly to stakeholders and provided recommendations for future development

### Technologies & Methods
- Python
- Convolutional Neural Networks (CNN)
- ResNet / DenseNet
- X-ray Image Classification
- Data Cleaning & Preprocessing
