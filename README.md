# Catheter-Project

Overview

This project involved developing a Convolutional Neural Network (CNN) to analyse X-ray images and classify different catheter types and their placement as normal or abnormal.

The project explored the potential application of deep learning in hospital settings, particularly in emergency departments, where automated detection of high-risk catheter misplacements could help support faster clinical decision-making.

Objectives
Develop a CNN capable of analysing X-ray images.
Classify different types of catheters.
Identify whether catheter placement is normal or abnormal.
Investigate different deep learning architectures to improve model performance.
Address data quality and class imbalance challenges within the dataset.

Key Takeaway

This case study demonstrated how deep learning and medical image classification could potentially assist healthcare professionals in identifying abnormal catheter placements. While the project was developed as a case study rather than a clinical deployment, it highlighted the potential for CNN-based systems to support early detection of high-risk catheter misplacements in hospital environments.
